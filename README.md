# 📊 Sales Performance Dashboard | Microsoft Excel

An interactive **Sales Performance Dashboard** developed using Microsoft Excel to analyze sales trends, product performance, customer segments, and business performance over time.

This project demonstrates practical skills in **data cleaning, data analysis, PivotTables, PivotCharts, slicers, timelines, and dashboard design**.

## 🎯 Project Objective

The objective of this project is to transform raw sales data into an interactive and visually intuitive dashboard that helps users:

- Monitor overall sales performance
- Identify yearly sales trends
- Analyze sales by category
- Compare customer segments
- Explore product-level performance
- Filter and interact with the data dynamically

## 📊 Dashboard Features

### Sales Trend Analysis
Analyzes sales performance across different years to identify growth and changes over time.

### Category Analysis
Allows users to compare sales performance across different product categories.

### Customer Segment Analysis
Provides insights into sales generated by different customer segments.

### Product Analysis
Helps identify high-performing products and understand product-level sales performance.

### Interactive Filters
The dashboard includes interactive **Slicers** and a **Timeline**, allowing users to dynamically filter the dashboard and explore specific parts of the dataset.
